# Omni Presenter 0.8.5-alpha

> Release notes for version `0.8.5-alpha`.

## Highlights

- **Design Studio Bottom Dock Architecture & Alignment:** Completely restructured the animation and filmstrip bottom dock card in the Design Studio using the unified `panel(&theme)` frame system. Positioned directly spanning the full center area width (`center_rect.min.x` to `center_rect.max.x`) and anchored at container base (`area.bottom()`), achieving exact pixel alignment with the left sidebar and right inspector panels.
- **Smooth Vertical Dock Resizing:** Integrated a top-edge splitter handle directly on the dock card's upper border with `CursorIcon::ResizeVertical` and interactive glow feedback, allowing operators to resize the animation dock smoothly between 24px and 420px. Double-clicking the top edge quickly toggles between collapsed (44px) and expanded states.
- **Zero-Clipping Card Geometry & 12px Rounded Corners:** Eliminated nested frames and artificial minimum height overrides. The dock card is rendered cleanly with `corner_radius(12.0)` on all four corners (top-left, top-right, bottom-left, bottom-right). All inner content (header bar, ruler, and layer tracks) strictly respects available container space, guaranteeing that borders are never cut off either initially or when resized.
- **Forward-Flow Responsive Header Bar:** Completely eliminated header widget collisions and text overlaps (e.g. `0.0s / 5.0s` colliding with "Linha do tempo") by adopting a single forward-flowing layout with dynamic spacer calculation that gracefully adapts across all viewport widths.
- **Timeline Ruler Label Precision & Track Inset:** Added right padding (`end_pad = 14px`) to both the ruler track and layer lanes, ensuring terminal time markers (e.g., `5s`) and layer bars retain comfortable breathing room and never collide with or clip against the right border.
- **Timeline Handle Gutter Precision:** Clamped horizontal timeline drag handle zones strictly within layer bar boundaries, preventing unintended resize cursor triggers (`<->`) when hovering in the gutter between layer labels and timeline tracks.
- **Design Studio Canvas Shortcuts & Editing Productivity:** Integrated standard keyboard shortcuts for canvas manipulation, including `Ctrl+C` (copy layers), `Ctrl+X` (cut layers), `Ctrl+V` (paste layers, images, or text), `Ctrl+D` (duplicate layers), `Delete` / `Backspace` (delete selected layers), `Ctrl+A` (select all), `Escape` (deselect), `Ctrl+Z` / `Ctrl+Y` (undo / redo), and arrow key nudge (1px, or 10px with Shift).
- **External Image Drag-and-Drop:** Added direct drag-and-drop of image files (PNG, JPG, WebP, GIF, BMP, SVG) from the desktop or file manager straight onto the design canvas, featuring an intuitive visual dropzone cue with accent border and icon overlay.
- **Clipboard Image Pasting:** Pasting directly from the system clipboard (`Ctrl+V`) automatically detects copied screenshots, image data, and image file paths, importing and inserting them instantly as image layers on the active slide.
- **Transparent Slide Preview & OS Desktop Wallpaper Integration:** Standalone designs and slides with transparent backgrounds (`background_mode: "transparent"`) now display the configured physical wallpaper or host desktop background in the stage preview and live viewports instead of forcing presentation themes or flat dark boxes. Automatically detects native operating system wallpapers across Linux (GNOME, Cinnamon, MATE, KDE Plasma, XFCE), Windows, and macOS, faithfully reflecting what physical screens project.
- **Rounded Corner Masking for Previews & Live Viewports:** Integrated high-precision 16-step corner masking (`paint_corner_mask`) with outward boundary padding across stage live viewports, preview viewports, theme creator previews, and theme cards. Ensures that inner rectangular content (textures, shaders, video frames, design layers, desktop backdrops) never bleeds square pixels outside the rounded stroke, completely eliminating corner leaks.
- **Global Search & Playlist Refinements:** Refined the global command palette search input with improved vertical centering (`LEFT_CENTER`) and standardized status circle checkmark scaling across playlist columns.

## Detailed Features & Changes

### 1. Design Studio Animation Dock Layout & Alignment
- Separated the central editor area into independent canvas (`top_ui`) and animation dock (`dock_ui`) viewports.
- Anchored the dock card's bottom border directly to `center_rect.max.y` (`area.bottom()`), perfectly aligning its base with the left sidebar and right inspector cards.
- Applied symmetric lateral insets matching the canvas margins (`center_rect.min.x + 6.0` to `center_rect.max.x - 6.0`), isolating the dock from vertical column splitters and ensuring all 4 rounded corners (`12.0px`) remain visible and unobstructed.
- Defaulted initial timeline height to a compact 38px (~120px to 124px total card height) for a clean workspace that prioritizes canvas editing space upon opening.

### 2. Interactive Dock Splitter & Resizing
- Added a dedicated top splitter drag handle with visual grip indicator, hover/active animations, and `CursorIcon::ResizeVertical`.
- Dragging the handle adjusts `editor.timeline_height` smoothly between `36.0px` and `500.0px`.
- Double-clicking the splitter toggles between compact (38px) and expanded (160px) presets.
- Header cycle button cycles through compact (38px), medium (140px), and tall (260px) heights with immediate repaint.

### 3. Strict Scroll Bounds & Anti-Clipping Protection
- Constrained `ScrollArea::vertical` for layer tracks and `ScrollArea::horizontal` for slide filmstrips to `(ui.available_height() - 6.0)`, strictly guarding the 8px bottom frame margin and 1px border stroke.
- Enabled `auto_shrink([true, false])` on the tracks scroll area so single-layer designs do not reserve unnecessary empty space.
- Capped thumbnail height in Slides mode dynamically to available space, preventing slide cards from overflowing the container.

### 4. Responsive Header Bar & Timeline Ruler
- Header controls dynamically adjust widths and switch to compact labels (e.g., "Prévia", "Linha") when the central column width falls below 640px or 520px.
- Right-to-left header layout checks remaining horizontal space before drawing duration edit and time counter labels, preventing text collisions over the mode selector.
- In `animation_timeline.rs`, timeline ruler marks now evaluate `is_last`: terminal marks (e.g., `5s`) use `Align2::RIGHT_TOP` with 3px inset padding, keeping all second labels fully contained within the ruler background.

### 5. Design Studio Shortcuts, Clipboard & Drag-and-Drop
- Registered new commands `CopyLayer` (`Ctrl+C`), `CutLayer` (`Ctrl+X`), and `PasteLayer` (`Ctrl+V`) across application commands, keyboard shortcut capture, and localization files.
- Layer duplication and deletion now respond seamlessly to `Ctrl+D` and both `Delete` / `Backspace`.
- Direct arrow key nudging (`ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`) allows fine-grained repositioning of selected layers by 1px (or 10px with `Shift`).
- Implemented canvas-level file drop detection (`handle_canvas_file_drop`): hovering an image over the canvas displays a semi-transparent dropzone preview with accent border, and releasing the file imports and inserts it directly at the dropped position.
- Added clipboard image support (`arboard`): pressing `Ctrl+V` detects image data or screenshot buffers from the system clipboard, thumbnails oversized images to safe dimensions, and inserts them as layers.
- Text or serialized layers can also be pasted or copied to external applications.

### 6. UI Polish & Component Standards
- **Corner Masking on Preview Cards:** Added corner masking across stage previews (`render_preview_column`), live viewports (`render_stage_column`), theme cards (`render_themes_column`), and the theme creator canvas preview. Inner quad meshes and textures that render full rectangles are cleanly masked along all four rounded corners before the border stroke is drawn, preventing rectangular corners from protruding past rounded container borders.
- **Global Search:** Updated search text edit height to 48px with `Align2::LEFT_CENTER` for better vertical text alignment and balanced padding.
- **Playlist Status Circle:** Standardized `STATUS_CIRCLE_RADIUS` to 5.2px with proportional checkmark stroke scaling and added dedicated unit tests for state rendering.

### 7. Transparent Slide Backgrounds & Desktop Wallpaper Integration
- Standalone slides with `background_mode: "transparent"` now retain explicit transparency and no longer force or inherit theme backgrounds in `ContainerKind::Themes` or stage previews.
- In both preview and live output containers (`render_preview_column` and `render_stage_column`), transparent slides render over the operator's configured physical wallpaper (`PhysicalBackground`) or host desktop background.
- Added cross-platform desktop wallpaper auto-detection service (`src/services/desktop_wallpaper.rs`), probing system desktop wallpaper configurations on Linux (GNOME/Cinnamon/MATE gsettings, `~/.config/background`, KDE Plasma, XFCE), Windows (Desktop Wallpaper registry), and macOS (Finder AppleScript).
- Integrated `paint_wallpaper_with_radius` supporting custom corner radii and fallback patterns, ensuring smooth 12px rounded borders and realistic desktop preview backdrops across floating previews, settings, and stage monitors.
