# Omni Presenter 0.8.5-alpha

> Release notes for version `0.8.5-alpha`.

## Highlights

- **Design Studio Bottom Dock Architecture & Alignment:** Completely restructured the animation and filmstrip bottom dock card in the Design Studio. Decoupled dock positioning from the canvas internal view and anchored it cleanly at the container base (`area.bottom()`), achieving seamless horizontal alignment with the sidebar and inspector panels.
- **Smooth Vertical Dock Resizing:** Added an intuitive top splitter handle with vertical resize cursor and interactive feedback, allowing operators to resize the animation dock smoothly between 36px and 500px. Double-clicking the handle quickly toggles between compact (38px) and expanded (160px) heights, with an additional cycle button in the header.
- **Zero-Clipping Card Geometry & 12px Rounded Corners:** Strictly clamped layer track and slide filmstrip scroll areas to available inner height, preventing content from pushing card borders off-screen. All four rounded corners (12.0px radius matching the app design system) and border strokes remain fully visible without clipping, both at default compact sizes and when resized.
- **Responsive Header Bar:** Play/pause button, segmented mode toggle ("Linha do tempo" / "Slide"), time scrubbers, and right-to-left duration controls now dynamically adapt their widths and labels on narrower viewports, preventing widget collision or text overlap.
- **Timeline Ruler Label Precision:** Fixed the final timestamp marker on the timeline ruler (e.g., `5s`) by aligning it to the right of the end tick (`Align2::RIGHT_TOP`), ensuring the terminal time marker sits neatly inside the ruler track instead of hanging outside the card boundary.
- **Global Search & Playlist Refinements:** Refined the global command palette search input with improved vertical centering (`LEFT_CENTER`) and standardized status circle checkmark scaling across playlist columns.

## Detailed Features & Changes

### 1. Design Studio Animation Dock Layout & Alignment
- Separated the central editor area into independent canvas (`top_ui`) and animation dock (`dock_ui`) viewports.
- Anchored the dock card's bottom border directly to `center_rect.max.y` (`area.bottom()`), perfectly aligning its base with the left sidebar and right inspector cards.
- Applied symmetric lateral insets matching the canvas margins (`center_rect.min.x + 6.0` to `center_rect.max.x - 6.0`), isolating the dock from vertical column splitters and ensuring all 4 rounded corners (`12.0px`) remain visible and unobstructed.
- Defaulted initial timeline height to a compact 38px (~120px to 124px total card height) for a clean workspace that prioritizes canvas editing space upon opening.

### 2. Interactive Dock Splitter & Resizing
- Added a dedicated top splitter drag handle with visual grip indicator, hover/active animations, and `CursorIcon::ResizeVertical`.
- Dragging the handle adjusts `editor.timeline_height` smoothly between `36.0px` and `500.0px`.
- Double-clicking the splitter toggles between compact (38px) and expanded (160px) presets.
- Header cycle button cycles through compact (38px), medium (140px), and tall (260px) heights with immediate repaint.

### 3. Strict Scroll Bounds & Anti-Clipping Protection
- Constrained `ScrollArea::vertical` for layer tracks and `ScrollArea::horizontal` for slide filmstrips to `(ui.available_height() - 6.0)`, strictly guarding the 8px bottom frame margin and 1px border stroke.
- Enabled `auto_shrink([true, false])` on the tracks scroll area so single-layer designs do not reserve unnecessary empty space.
- Capped thumbnail height in Slides mode dynamically to available space, preventing slide cards from overflowing the container.

### 4. Responsive Header Bar & Timeline Ruler
- Header controls dynamically adjust widths and switch to compact labels (e.g., "Prévia", "Linha") when the central column width falls below 640px or 520px.
- Right-to-left header layout checks remaining horizontal space before drawing duration edit and time counter labels, preventing text collisions over the mode selector.
- In `animation_timeline.rs`, timeline ruler marks now evaluate `is_last`: terminal marks (e.g., `5s`) use `Align2::RIGHT_TOP` with 3px inset padding, keeping all second labels fully contained within the ruler background.

### 5. UI Polish & Component Standards
- **Global Search:** Updated search text edit height to 48px with `Align2::LEFT_CENTER` for better vertical text alignment and balanced padding.
- **Playlist Status Circle:** Standardized `STATUS_CIRCLE_RADIUS` to 5.2px with proportional checkmark stroke scaling and added dedicated unit tests for state rendering.
