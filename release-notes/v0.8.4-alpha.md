# Omni Presenter 0.8.4-alpha

> Release notes for version `0.8.4-alpha`.

## Highlights

- **Desktop File Association & Double-Click Import:** Double-clicking supported files (`.hinos`, `.hino`, `.letras`, `.txt`, `.omnipresenter-lyrics`, `.omnipresenter-text`, `.omnipresenter-design`, `.omnipresenter-theme`, `.omnipresenter-playlist`, `.omnipresenter-backup`) in your file manager now automatically opens and imports them into Omni Presenter. A single-instance IPC listener ensures files opened while the application is already running are cleanly dispatched and imported into the active session with immediate visual feedback.
- **Operator Chat File Sharing & One-Click Import:** Operators can now drag, drop, or upload presentation items (songs, texts, designs, themes, playlists) directly into team chat. Shared files render rich visual cards with an interactive "Import" button, allowing team members to import received files into their local library with a single click.
- **Missing Font Detection & Theme Font Resolution:** Importing themes or opening presentations containing fonts not present on the host system now automatically detects missing typefaces. An interactive Font Resolution dialog allows operators to supply the missing font file (`.ttf` / `.otf`), register it directly into the application's font database, and dynamically inject it into the UI renderer without restarting the app.
- **Universal Context Menu Export:** Right-clicking any item across the entire workspace now exposes a dedicated **Export** action. Available for Songs, Texts, Designs, Themes, and Playlists. When exporting a complete playlist, Omni Presenter automatically inspects the items and opens a dialog asking whether associated media files should be bundled into the package (only when media items are present).
- **Folder-Independent Library Search with Title-First Ranking:** Searching in the library selection column (Songs, Media, Texts, Verses) now flattens the result list across all folders, eliminating accordion clutter and ensuring items outside folders are never buried at the bottom. Songs matching the title rank ahead of matches in the lyrics or body, while origin folders remain neatly noted in the card subtitle. Clearing the search instantly restores the organized folder hierarchy.

## Detailed Features & Changes

### 1. File Association & Single-Instance IPC Dispatch
- Registered desktop MIME types and `.desktop` / `.xml` associations for Linux and desktop file managers.
- Added command-line path handling on startup to parse and import passed files immediately.
- Implemented single-instance local IPC socket:
  - If an instance of Omni Presenter is already running, double-clicking a file sends the target path to the running instance over the socket and gracefully exits the launching process.
  - The running instance receives the payload, executes the appropriate import pipeline (songs, texts, designs, themes, or playlists), displays a confirmation toast, and requests a frame repaint.

### 2. Chat File Transfer & Interactive Cards
- Added support for attaching and sending supported presentation files via the operator chat message stream.
- Message rendering renders specialized payload cards indicating the resource type, name, and size.
- Direct **Import** action button within chat messages allows operators to import shared songs, designs, themes, or playlists into their workspace with one click.

### 3. Font Detection & Resolution System
- Theme and presentation import verifies that all referenced fonts are available in `fontdb` or system fonts.
- If an unknown font family is encountered:
  - The application opens the **Font Resolution Modal** detailing the missing font family.
  - Operators can pick a local `.ttf` or `.otf` file or select a fallback font.
  - The font is dynamically registered into `custom_fonts` and loaded into the active `egui::Context` via `FontInsert` on the fly.

### 4. Context Menu Export
- **Songs & Texts:** Right-click context menu includes **Export song** / **Export text** (`.omnipresenter-lyrics` / `.omnipresenter-text`).
- **Designs:** Right-click context menu in the design library includes **Export design** (`.omnipresenter-design`).
- **Themes:** Right-click context menu on theme cards includes **Export theme** (`.omnipresenter-theme`).
- **Playlist / Repertoire:** Right-click menu and header include **Export playlist** (`.omnipresenter-playlist`). If the playlist contains video or audio media files, an interactive prompt asks whether to bundle media files into a self-contained archive.

### 5. Unified Flat Search & Relevance Ranking
- When a search query is active in the selection column:
  - Folder accordion headers are hidden so results are immediately accessible in a flat, unified list.
  - Items matching the query at the beginning of the title rank first.
  - Items with the query anywhere in the title rank second.
  - Items with all search words in the title rank third.
  - Items matching only in the lyrics, description, or body rank after title matches.
  - Search items display their origin folder in the subtitle tag so folder context is never lost.
- When the search query is empty, the complete tree structure with folders, item counts, and collapse states is preserved.

## Improvements & Fixes

- Fixed library search bar layout and styling: resolved horizontal container overflow and splitter cutting by calculating exact pixel-fitting dimensions, added proper vertical spacing and separator against list items, and refined the search input and close button with modern rounded pill styling and Phosphor icons.
- Fixed instant library synchronization on import: newly imported songs, texts, and designs are now immediately refreshed in the active slide deck and selection column without requiring an application restart.
- Fixed collapsible conditions and clamp bounds across settings and transfer modules.
- Refactored `selection` model and actions to keep individual source files strictly below the 1000-line architecture limit.
- Updated Clippy baseline and ensured zero new lint warnings across all targets.
- Fixed texture delta cleanup in headless egui test runners.
